# Monster Registry

## Status
Canonical registry for persistent recurring/material Monster individuals.

## Active Entries

No persistent Monster individual is currently registered.

## Rules
- Encounter-only Monster does not receive a `MONSTER_ID`.
- A recurring/material individual requiring continuity receives a unique, stable `MONSTER_ID` and a Current Monster State/History according to `systems/13_MONSTERS.md`.
- This registry is not a species catalog and does not instantiate a Monster by itself.
- Permanent-dead/archived IDs are never reused.

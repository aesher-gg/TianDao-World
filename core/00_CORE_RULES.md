# 00 — Core Rules

## Status
Fondasi aturan utama TianDao-World. Modul ini menjadi konstitusi permainan.

## Prinsip
- Hardcore realism.
- Anti-cheat dan anti-retcon.
- World Bible sebagai sumber kebenaran.
- NPC dan dunia berjalan secara otonom.
- Tidak ada plot armor.
- Konsekuensi permanen kecuali ada dasar resmi.
- Player tidak dapat mengubah fakta dunia hanya melalui klaim.

> Aturan lengkap akan difinalisasi sebelum sistem permainan aktif.

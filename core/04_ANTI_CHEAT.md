# 04 — ANTI-CHEAT

GM menolak klaim item tanpa sumber, teknik tanpa proses sah, perubahan status tanpa sebab, time skip tersembunyi, auto-hit/auto-kill, retcon, aksi berantai ilegal, identitas NPC dari meta-knowledge, dan meta-gaming.

Inventory wajib memiliki sumber: pembelian, loot, atau pemberian tercatat. Current Character State menjadi sumber kondisi setelah karakter mulai dimainkan; players.md tetap katalog awal.

Combat mengikuti hit chance, damage, defense, realm gap, kondisi, dan resource resmi. Player tidak dapat mengklaim serangan mengenai titik vital tanpa resolusi.

Pelanggaran pertama diberi peringatan; pengulangan mendapat konsekuensi in-character; pelanggaran berat/berulang dapat menghentikan sesi.

# 03 — ACTION SYSTEM

Pipeline: Intent → Context → Validation → Cost → Resolution → Consequence → Log.

Dalam situasi kritis, satu prompt hanya satu aksi utama. GM memvalidasi lokasi, jarak, waktu, kondisi, HP/Qi/Stamina/Satiety, teknik, realm, equipment, inventory, target, informasi karakter, event aktif, dan batas waktu.

Biaya dapat berupa waktu, stamina, Qi, currency, item, durability, makanan, atau resource lain sesuai modul. Hasil tidak pernah ditentukan sendiri oleh player; dapat sukses, gagal, sebagian berhasil, atau menghasilkan konsekuensi.

Deskripsi ambigu tidak boleh dieksploitasi. GM dapat meminta klarifikasi atau memilih interpretasi konservatif dan realistis.

## DATA COMPLETENESS ACTION GATE
Sebelum Context → Validation → Cost → Resolution, field material yang belum tersedia wajib diklasifikasikan menurut core/07_DATA_COMPLETENESS.md. Ambiguity boleh diselesaikan hanya melalui interpretasi konservatif yang tidak menciptakan fakta baru; jika required fact tidak tersedia dan tidak ada fallback resmi, resolusi harus ditahan.

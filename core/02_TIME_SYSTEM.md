# 02 — TIME SYSTEM

Waktu adalah state dunia dan hanya berubah melalui aksi/event yang valid.

- Aksi non-kultivasi: maksimal 3 jam per turn.
- Kultivasi murni: maksimal 1 bulan jika seluruh checklist retret terpenuhi.
- Retret panjang wajib memakai checkpoint.
- Maksimal 3 bulan kultivasi intensif berturut-turut; setelahnya minimal 1 minggu istirahat.
- Tidak ada time skip tersembunyi.
- Tahun, musim, tanggal, hari, dan jam mengikuti lore/CALENDAR.md.
- Durasi perjalanan, pekerjaan, pemulihan, combat, dan aktivitas lain harus ditentukan secara realistis dan dicatat.

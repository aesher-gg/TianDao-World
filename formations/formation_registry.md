# Formation Registry

## Status
Admin Canon v1.0

Registry ini hanya mencatat Formation/Array yang memang dipersistenkan. Dynamic one-turn non-material Formation tidak otomatis masuk registry.

## ID Rules
- Formation ID: `FORM-####`
- Array Core ID: `ARRAYCORE-####`
- ID unik, stabil, dan tidak pernah dipakai ulang.
- Identity tidak berubah karena nama, lokasi, owner, status, atau condition.

## Entries
Belum ada persistent Formation/Array yang terdaftar.

# 18 — LOOT

## 1. Sumber
Loot berasal dari:
- monster/spirit beast;
- peti atau lokasi;
- musuh;
- event;
- reward misi;
- sumber resmi lainnya.

## 2. Validasi
Loot hanya diberikan setelah kondisi perolehan terpenuhi. GM tidak menjamin item langka.

## 3. Loot Table
Jika loot table resmi tersedia, gunakan table tersebut. Jika tidak ada table, GM tidak membuat drop spesifik dan dapat menyatakan bahwa hasil belum dapat ditentukan dari World Bible.

## 4. Kepemilikan
Loot yang berhasil diperoleh langsung menjadi bagian dari Item Origin Log dengan sumber dan timestamp.

## 5. Distribusi
Jika beberapa pihak berhak atas loot, pembagian mengikuti kepemilikan, kesepakatan, hukum faction, atau hasil konflik yang sah.

## 6. Integrasi
Loot terhubung dengan Combat, Monsters, Events, Items, Economy, Organizations, Karma, Reputation, dan Save Integrity.

## 7. Anti-Duplikasi
Item unik/terbatas tidak dapat diduplikasi melalui klaim player, reload state, atau retcon.

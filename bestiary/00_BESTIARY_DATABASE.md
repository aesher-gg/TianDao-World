# BESTIARY DATABASE — ADMIN CANON v1.3

## Status
Admin Canon. Fixed Bestiary adalah referensi resmi untuk creature yang memang ditetapkan; Dynamic Generation tetap dapat menghasilkan creature di luar fixed entries bila rule mengizinkan.

## Boundary
Fixed entry tidak otomatis berarti encounter, taming, ownership, ability, loot, atau relationship. Encounter aktual mengikuti Dynamic Encounter/Generation dan Current State.

## Core Rules
- Fixed Bestiary bukan batas species dunia.
- Creature di luar fixed entry dapat dihasilkan secara dinamis bila habitat, region, environment, time, event, threat, dan formula mendukung.
- Fixed entry diprioritaskan hanya ketika source encounter secara eksplisit merujuk entry tersebut.
- Tidak ada default Monster Core atau Spirit Beast Core kecuali source spesifik menetapkannya.
- Meat/material/loot hanya diperoleh bila anatomy, resolution, dan loot rule mendukung.
- Special Material tidak otomatis berarti Rare/Very Rare/Exceptional.
- Character Realm tidak otomatis menaikkan Tier atau kualitas loot.
- Tidak ada automatic technique, artifact, currency, breakthrough, atau Core dari entry ini.

## Origin / Canon Source
Admin-established Bestiary Canon v1.3.

## Persistence
Entry fixed Bestiary bersifat Canon. Encounter aktual, kondisi individual creature, hasil loot, Spirit Beast relationship/ownership, dan perubahan runtime tetap harus dicatat melalui state/history/origin sesuai modul terkait.

## Resolution & Validation
Jika fixed entry berlaku, GM mengambil data entry sebagai source fixed dan tetap menjalankan validation. Jika tidak berlaku, gunakan Dynamic Generation. Fixed entry tidak boleh digunakan untuk memberikan atribut yang tidak tercatat.

## Priority
`Fixed Canon Bestiary → Fixed Event/Mission Source → Dynamic Generation → RESOLUTION-BLOCKED`

Jika source yang diperlukan untuk resolusi tidak tersedia, jangan mengarang creature/loot/result. Tahan resolusi atau gunakan fallback resmi yang tersedia.

## Anti-Catalog
Creature hasil Dynamic Generation tidak otomatis masuk database. Penambahan fixed creature harus melalui perubahan Admin Canon dan write-back terverifikasi.

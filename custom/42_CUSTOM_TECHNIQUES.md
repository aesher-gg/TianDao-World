# 42 — Custom Techniques

## Status
Admin Canon — registry aktif; saat ini tidak ada Custom Technique yang diaktifkan.

## Boundary
File ini adalah sumber resmi untuk teknik/jurus kustom yang secara eksplisit ditetapkan Admin. Tidak ada entry berarti tidak ada Custom Technique aktif; GM tidak boleh menciptakan teknik fixed dari improvisasi runtime.

## Entry Schema
Setiap Custom Technique yang ditambahkan wajib memiliki:
- `TECH_ID`
- Nama teknik
- Kategori
- Sumber/Origin
- Metode Akuisisi
- Syarat penggunaan
- Tahap/Realm yang didukung
- Biaya
- Efek mekanis
- Batasan
- Risiko
- Mastery progression
- Origin Log
- Status lifecycle

## Active Registry
`EMPTY — tidak ada Custom Technique aktif.`

## Runtime Rule
Teknik yang muncul dari Dynamic Generation tidak otomatis menjadi Custom Canon. Teknik baru hanya dapat menjadi kemampuan aktif setelah source, acquisition, training, requirements, resolution, Technique Origin, dan validation terpenuhi.

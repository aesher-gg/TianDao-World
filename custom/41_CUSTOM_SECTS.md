# 41 — Custom Sects

## Status
Admin Canon — registry aktif; saat ini tidak ada Custom Sect/Dojo/Organization yang diaktifkan.

## Boundary
File ini adalah sumber resmi untuk organisasi kustom yang secara eksplisit ditetapkan Admin. Tidak ada entry berarti tidak ada organisasi kustom aktif; GM tidak boleh membuat organisasi kustom fixed dari improvisasi runtime.

## Entry Schema
Setiap organisasi kustom yang ditambahkan wajib memiliki:
- `ORG_ID`
- Nama organisasi
- Kategori
- Wilayah
- Fokus dan agenda
- Struktur internal
- Rekrutmen/akses
- Relasi
- Sumber/Origin
- Teknik atau fasilitas khusus bila ada
- Membership/rank rules
- Persistence boundary
- Origin Log
- Status lifecycle

## Active Registry
`EMPTY — tidak ada Custom Sect/Dojo/Organization aktif.`

## Runtime Rule
Organisasi dinamis dapat dibuat hanya melalui Module 26 dan tidak otomatis menjadi Custom Canon. Organisasi kustom fixed hanya aktif setelah entry Admin tersimpan dan tervalidasi.
